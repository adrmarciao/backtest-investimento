## Why

The current layout of the expenses screen is not visually appealing and the placement of components is suboptimal for the user experience. Redesigning the screen will improve usability by placing the primary content (the list of expenses) at the top where it's immediately visible, and secondary actions (the QR code) at the bottom.

## What Changes

- Redesign the expenses screen UI to make it more modern and visually appealing.
- Move the expense list to the top of the screen.
- Move the QR code to the bottom of the screen.
- Polish visual elements (colors, spacing, typography) while keeping existing functionality intact.

## Capabilities

### New Capabilities
None.

### Modified Capabilities
None. This change is purely an aesthetic and layout redesign. Requirements and behavior remain the same. The change sets `skip_specs: true` in its `.openspec.yaml`.

## Impact

- Frontend application only.
- Will affect the UI structure and styling of the expenses screen component(s).
- No API or backend changes are required.
